Recommended Workflow (Surgical & Safe)

  1. Upload your unencrypted JSON vault export to identify duplicates.
  2. Select the items you wish to remove.
  3. Click "Get CLI Deletion Script" and run the generated commands.
  4. Why? This surgically moves items to your Vault Trash. Your original records (TOTP, Passkeys, etc.) remain recoverable if needed.

Alternative: JSON Export (For Migrations)

Use this only if importing to a new/empty vault or a different password manager (e.g., 1Password, Proton Pass).

Step 1: Export your Vault (Unencrypted JSON)

  1. Log in to your Bitwarden Web Vault.
  2. Navigate to Tools → Export Vault.
  3. Select .json as the Format (Warning: Do not select Encrypted JSON).
  4. Enter your Master Password and click Export Vault.
  1. Open your terminal and login: bw login
  2. Unlock your vault: export BW_SESSION="$(bw unlock --raw)" (Bash) or $env:BW_SESSION = bw unlock --raw (PowerShell)
  3. Run export command: bw export --format json --output vault.json
  4. Use the resulting vault.json file in the upload zone below.
