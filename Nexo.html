Ready to clean up?

  1. Follow the instructions in Step 1 to export your Bitwarden vault to a JSON file and drag upload it into the page.
  2. Select the items you wish to remove or merge.
  3. Click "Get CLI Action Scripts" and run the generated commands.

You may also choose to export a "cleaned" JSON file and re-import it to your vault instead of the CLI approach above, but this is only recommended for certain use cases, e.g. backup, importing to a new/empty vault or migrating to a different password manager (e.g., 1Password, Proton Pass).

⚠️ Warning:

Importing JSON into a populated Bitwarden vault could create massive duplication of data and may require extensive manual cleanup. Only do so at your own risk.

Step 1: Export your Vault (Unencrypted JSON)

  1. Log in to your Bitwarden Web Vault.
  2. Navigate to Tools → Export Vault.
  3. Select .json as the Format (Warning: Do not select Encrypted JSON).
  4. Enter your Master Password and click Export Vault.

  3. If you are not already logged in, run bw login once.
  4. Unlock your vault: export BW_SESSION="$(bw unlock --raw)" (Bash) or $env:BW_SESSION = bw unlock --raw (PowerShell)

Bitwarden CLI Action Scripts

Run in Bash

  1. Install Bitwarden CLI and make sure bw is available in your terminal.
  2. If this is a fresh shell, log in first with bw login.
  3. Save the script to a file such as nexo-actions.sh.
  4. Make it runnable with chmod +x nexo-actions.sh.
  5. Run it with ./nexo-actions.sh or bash nexo-actions.sh.
  6. The script sets BW_SESSION itself and returns control to your shell when it finishes.

Run in PowerShell

  1. Install Bitwarden CLI and make sure bw is available in PowerShell.
  2. If this is a fresh session, log in first with bw login.
  3. Save the script to a file such as nexo-actions.ps1.
  4. If PowerShell blocks local scripts, allow this session with Set-ExecutionPolicy -Scope Process Bypass.
  5. Run it with .\nexo-actions.ps1 or pwsh -File nexo-actions.ps1.
  6. The script sets BW_SESSION itself and returns control to your shell when it finishes.
